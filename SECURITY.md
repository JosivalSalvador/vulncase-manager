# Política de Segurança

## Versões com suporte

Este é um projeto acadêmico (VulnCase Manager). Apenas a versão mais recente da branch `main` recebe correções de segurança.

## Como reportar uma vulnerabilidade

Não abra uma issue pública. Use o relato privado do GitHub:

1. Vá na aba de segurança do repositório (**Security**).
2. Clique em **Report a vulnerability**.
3. Descreva o problema, os passos para reproduzir e o impacto.

## O que esperar

- Confirmação de recebimento em até 7 dias.
- Atualização sobre a análise e a correção assim que houver novidades.
